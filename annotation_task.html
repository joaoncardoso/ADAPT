SAE Feature Interpretability Annotation

Instructions

For each feature, you will see:

  • Explanation: A description of what the feature detects
  • Max Activating Examples: Real text examples where the feature activates (highlighted tokens show activation strength)
  • Generated Prompts: Three prompts generated by different methods (order randomized)

Your task: Rate each prompt from 1-5:

  • 1: No discernible pattern
  • 2: Pattern in the semantic ballpark of reference examples, but otherwise uninterpretable
  • 3: Pattern understandable, but not discernible from optimized prompt alone
  • 4: Pattern is present, but different in some way (e.g. different language) from reference examples
  • 5: Pattern is obvious and matches examples

Click "Neuronpedia ↗" to see more examples or test prompts interactively.

Additional guidance:

  • Some generated prompts may come in foreign languages. If you need to, ask ChatGPT to translate a token to confirm or deny a hypothesis.
  • The maximal activation is in the last position (before the square brackets). If a description says "Fires for Y", then Y should be in the last position. The prompts are gibberish, and you shouldn't expect well-formed sentences. For instance, for a feature that fires for "potato" you should rate the gibberish prompt HasAnnotation slov}{"||+#+igl Solve quicklyืpotato as a 5. For a feature described as "Firing for Marvel and MCU contexts", the prompt Hulk NatashaCapCap wehr Stark should similarly be rated as a 5.
  • Predicted next tokens are in square brackets. When feature description says "promotes X", it means that the model uses the feature to increase its prediction that X will come next. Thus, in the examples it may fire for plausible places for X to come next, even if X doesn't come.
  • If you are uncertain, rate the three prompts equally as 2 and move on. Remember that some of the explanations and features are low quality. Some explanations are marked as (uncertain).
